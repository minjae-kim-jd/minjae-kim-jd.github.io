# 할 일 목록 앱 점검표

`index.html`을 브라우저로 열어서 아래 항목을 하나씩 확인해 보세요. 체크박스는 확인했으면 `[ ]`를 `[x]`로 바꾸면 됩니다.

## 1. 기본 사용 (정상적인 경우)

- [ ] 입력칸에 글을 쓰고 "추가" 버튼을 누르면 목록에 추가된다
- [ ] 입력칸에 글을 쓰고 Enter 키를 누르면 목록에 추가된다
- [ ] 추가한 뒤 입력칸이 자동으로 비워진다
- [ ] 체크박스를 누르면 글자에 줄이 그어지고 회색으로 바뀐다
- [ ] 체크박스를 다시 누르면 원래대로(줄 없음, 검은 글자) 돌아온다
- [ ] "삭제" 버튼을 누르면 그 항목만 목록에서 없어진다
- [ ] 할 일을 몇 개 추가하고 일부 체크한 뒤 "남은 할 일: N개" 숫자가 맞는지 확인
- [ ] [전체] 버튼을 누르면 모든 항목이 보인다
- [ ] [할 일] 버튼을 누르면 체크 안 한 항목만 보인다
- [ ] [완료] 버튼을 누르면 체크한 항목만 보인다
- [ ] 지금 선택된 필터 버튼이 남색으로 표시된다
- [ ] 브라우저 탭/창을 완전히 닫고 다시 `index.html`을 열어도 목록과 체크 상태가 그대로 남아있다

## 2. 이상한 경우 (예외 상황)

- [ ] **빈 입력**: 아무것도 안 쓰고 "추가" 버튼이나 Enter를 누르면 — 빈 항목이 추가되지 않아야 함
- [ ] **공백만 입력**: 스페이스바만 몇 번 누르고 추가 — 빈 항목이 추가되지 않아야 함
- [ ] **같은 할 일 두 번 추가**: 똑같은 글자("우유 사기" 등)를 두 번 입력해서 추가 — 목록에 2줄로 각각 따로 추가되고, 하나를 체크하거나 삭제해도 다른 하나는 영향받지 않아야 함
- [ ] **아주 긴 글**: 100자 이상의 긴 문장을 입력해서 추가 — 글자가 화면 밖으로 넘치거나 레이아웃이 깨지지 않고, 줄바꿈되어 카드 안에 보여야 함
- [ ] **할 일 30개 추가**: 짧은 할 일을 30개 정도 연달아 추가 — 목록이 아래로 길게 늘어나도 각 항목이 제대로 보이고, "남은 할 일" 개수도 정확해야 함
- [ ] **30개 중 일부만 체크 후 필터 전환**: 30개 중 10개만 체크한 뒤 [할 일]/[완료] 버튼을 눌러서 개수가 각각 20개/10개로 정확히 나뉘는지 확인
- [ ] **특수문자/이모지 입력**: `<script>`, `&`, `"`, 😀 같은 특수문자나 이모지를 입력해서 추가 — 글자가 그대로 화면에 보이고 이상한 코드로 실행되지 않아야 함
- [ ] **모두 삭제 후 상태**: 목록에 있는 모든 항목을 삭제 — "남은 할 일: 0개"로 표시되고, 목록은 빈 상태로 에러 없이 보여야 함
- [ ] **필터가 걸린 상태에서 체크**: [완료] 필터를 선택해 둔 상태에서, 아직 체크 안 된 할 일이 있다면 보이지 않아야 하고, [할 일] 필터에서 항목을 체크하면 그 항목이 화면에서 바로 사라져야 함(완료로 넘어갔으므로)
- [ ] **새로고침 후 빈 입력창 상태**: 할 일을 추가하지 않은 상태에서 새로고침해도 에러 없이 빈 목록("남은 할 일: 0개")이 보여야 함
- [ ] **화면 크기 줄이기**: 브라우저 창을 휴대폰 크기만큼 좁게 줄여도 입력칸, 버튼, 목록이 겹치거나 화면 밖으로 삐져나오지 않아야 함
