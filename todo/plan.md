# 할 일 목록 앱 계획 (index.html 한 파일)

## 배경 (Context)
`D:\claude-study\todo` 폴더는 현재 비어 있는 새 프로젝트입니다. 목표는 `index.html` 파일 하나에 화면(HTML) + 디자인(CSS) + 동작(JavaScript)을 모두 담아, 인터넷 연결이 없어도, 별도 프로그램 설치 없이, 그냥 더블클릭으로 브라우저에서 열어 쓸 수 있는 "할 일 목록" 앱을 만드는 것입니다. 외부 라이브러리(CDN)를 쓰지 않고 순수 HTML/CSS/JS로만 작성합니다.

이 문서는 코드를 만들기 전에, **어떤 순서로 만들지 + 화면을 어떻게 나눌지**만 정리한 계획입니다.

## 화면 구성 (레이아웃)
위에서 아래로 4개 구역:
1. **제목**: "할 일 목록"
2. **입력 줄**: 텍스트 입력창 + "추가" 버튼 (엔터키로도 추가 가능)
3. **필터 탭**: [전체] [할 일] [완료] 3개 버튼 — 지금 선택된 버튼은 색이 다르게 표시
4. **목록**: 각 항목마다 체크박스 + 할 일 글자(완료되면 줄 긋기) + 삭제(×) 버튼
5. **하단 줄**: "남은 할 일: N개" 표시

## 만드는 순서 (단계별 — 한 단계씩 확인받고 다음으로 진행)
1. **기본 틀(화면 모양)**: 데이터 저장 없이, 화면 구조와 디자인만 먼저 만듦. 가짜 항목 2~3개를 미리 넣어 레이아웃이 맞는지 확인.
2. **할 일 추가 기능**: 입력창에 글을 쓰고 "추가" 버튼이나 엔터키를 누르면 목록 맨 아래에 새 항목이 생기도록 함.
3. **완료 체크 & 삭제 기능**: 체크박스를 누르면 완료 표시(줄 긋기)가 되고, × 버튼을 누르면 그 항목이 목록에서 사라지도록 함.
4. **브라우저를 껐다 켜도 유지**: `localStorage`(브라우저가 내 컴퓨터에 데이터를 저장해 두는 기능, 로그인 없이 이 브라우저·이 PC에만 저장됨)를 사용해서, 추가/체크/삭제할 때마다 자동으로 저장하고, 페이지를 열 때 저장된 목록을 불러오도록 함.
5. **남은 개수 표시 + 필터**: 완료되지 않은 항목 수를 세어 하단에 보여주고, [전체]/[할 일]/[완료] 버튼을 누르면 그에 맞는 항목만 화면에 보이도록 함.

각 단계가 끝나면 브라우저로 직접 열어서 확인시켜 드리고, 승인받은 뒤 다음 단계로 넘어갑니다.

## 확인 방법 (완성 후)
- `index.html` 파일을 더블클릭하거나 크롬 같은 브라우저로 열어서 직접 사용해봄 (인터넷 연결 불필요)
- 할 일 추가 → 체크 → 삭제 → 필터 전환이 모두 되는지 확인
- 브라우저를 완전히 닫고 다시 열어도 목록이 그대로 남아있는지 확인
